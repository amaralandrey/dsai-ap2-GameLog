API v2

A API v2 responde em JSON em {{ base }}. A leitura do catálogo é pública. Os dados da sua conta e a escrita exigem um token pessoal, criado na página "Tokens da API" do seu perfil, enviado no cabeçalho Authorization: Bearer <token>. O cookie do navegador não vale na v2.

Cada token tem os escopos ler e/ou escrever e um limite de 60 requisições por minuto (cabeçalhos X-RateLimit-Limit e X-RateLimit-Remaining; ao passar do limite, 429 com Retry-After). As listagens aceitam page e per_page (até 50) e trazem proxima.

Exemplos

curl {{ base }}/jogos?q=hades&loja=gog
curl -H "Authorization: Bearer glp_..." {{ base }}/eu/diario?de=2026-11-01
curl -X PUT -H "Authorization: Bearer glp_..." -H "Content-Type: application/json" \
     -d '{"status": "jogando"}' {{ base }}/eu/status/hades
curl -X POST -H "Authorization: Bearer glp_..." -H "Content-Type: application/json" \
     -d '{"jogo": "hades", "jogada_em": "2026-11-20", "duracao": "1h30"}' {{ base }}/eu/diario

Entrada inválida responde 422 com {"erro", "campos"}.
